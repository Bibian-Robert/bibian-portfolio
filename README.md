# Bibian Nyaeru Robert — Portfolio

Personal portfolio for Bibian Nyaeru Robert, showcasing select projects that use data-driven geospatial evidence to inform decisions across domains such as health, climate resilience, and civil registration in Eastern and Southern Africa.

Built with React, Vite, and Tailwind CSS. Live at [bibian-robert.github.io/bibian-portfolio](https://bibian-robert.github.io/bibian-portfolio/).
